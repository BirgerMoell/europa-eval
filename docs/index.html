03 / METHOD

Parallel by design.
Inspectable by default.

EUROPA uses deterministic scoring wherever possible and makes every result carry its language, protocol and judge provenance.

  1. 01
    Hold templates constant

    Twelve semantic tasks repeat across all 36 language packs.

  2. 02
    Profile, don’t flatten

    Language, domain, task, coverage, weakest slice and uncertainty stay visible.

  3. 03
    Prefer deterministic checks

    Exact, numeric, JSON and format contracts run locally without a judge.

  4. 04
    Name the judge

    Open answers remain unscored until a pinned judge is configured.

  5. 05
    Separate protocols

    Reasoning on and off are distinct runs; model and judge revisions travel with every answer.

04 / RUN

One suite. Your endpoint.

The dependency-free core talks to hosted APIs and Ollama’s native chat endpoint. Transformers is an optional direct backend. Filter one language for diagnostics or run all 432 items for comparable evidence.

export OPENAI_API_KEY="…"
europa run \
  --backend openai-compatible \
  --base-url https://api.openai.com/v1 \
  --model YOUR_MODEL_ID \
  --revision PINNED_VERSION \
  --judge-backend openai-compatible \
  --judge-model YOUR_JUDGE_ID \
  --output results/runs/model-api.json
europa run \
  --backend ollama \
  --model gemma4:31b \
  --revision OLLAMA_MODEL_DIGEST \
  --language swe \
  --diagnostic \
  --output results/runs/gemma-swe.json
python3 -m pip install -e '.[local]'
europa run \
  --backend huggingface \
  --model /path/to/checkpoint \
  --revision CHECKPOINT_SHA \
  --output results/runs/model-hf.json
